# Éthique sur la blockchain

### La question centrale

Le débat porte sur les responsabilités liées à l'utilisation du réseau. Les participants s'interrogeront sur deux axes :

***À quel point les mineurs et les validateurs sont-ils responsables de l'éthique du réseau si celui-ci est utilisé pour des transactions moralement condamnables ?***

Pour débattre de l'éthique d'un outil, il faut d'abord en comprendre la mécanique. La blockchain est un réseau sans aucune autorité centrale où l'essentiel des actions prend la forme de requêtes — transaction ou exécution de code.

Chacune de ces requêtes doit être vérifiée par un acteur clé : le mineur ou le validateur. En contrepartie, il est rémunéré par des frais de transaction (les *gas fees*), payés en cryptomonnaie native de la blockchain concernée — Bitcoin sur Bitcoin, Ether sur Ethereum, Solana sur Solana.

Les validateurs vérifient d'abord la faisabilité des transactions avant de les inscrire dans un bloc. Ils s'affrontent ensuite dans une course mathématique pour sceller ce bloc de façon cryptographique et inaltérable, le vainqueur remportant seul la récompense.

La question se pose alors : si les mineurs et validateurs permettent techniquement ces transactions sans en connaître l'origine réelle, dans quelle mesure peuvent-ils être tenus responsables quand le réseau sert des activités moralement condamnables ?
